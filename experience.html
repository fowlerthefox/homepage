Career Mode // The build behind the analyst

CAREER
JOURNEY_

Not a job-by-job CV. This is the progression of the work: from operational problem solving, to analytics at scale, to public-sector decision support, teaching, research and data infrastructure.

Chapter 01

Operations created the analytical instinct

2010-2019 // Cooley Distillery

Start with the process

Warehouse and production work provided direct experience of operational systems, inventory and process constraints. Excel dashboards were used to monitor production KPIs, while Lean Six Sigma projects focused on improving bottling efficiency.

Unlocked: process thinking + KPI design + continuous improvement.
2019 // ESB

Move from reporting to analysis

Internal performance dashboards supported reporting, while NLP analysis of Trustpilot reviews introduced an unstructured-data problem: convert text feedback into evidence that could be interpreted at scale.

Unlocked: dashboarding + NLP + analytical communication.
2019-2022 // PayPal

Analytics in a high-risk environment

SQL and Tableau were used to detect emerging fraud trends. Classification and fuzzy name matching helped identify linked accounts, while a repeatable bi-weekly process supported account action and prevented approximately €100K per month in fraud.

Unlocked: SQL at scale + classification + fraud analytics + operational action.
2022-2025 // Pobal

Public-sector decision support

KPI reporting supported a national childcare funding programme valued at more than €250M. R and SQL automation reduced manual reporting time, dashboards supported monthly performance reviews, and analytical work fed into policy and operational decision-making.

Unlocked: public-sector analytics + automation + stakeholder reporting.
Teaching // Higher Education

Explain the tools, not just use them

Part-time lecturing in data visualisation covered Excel, Power BI, Tableau and R Shiny. Teaching strengthened the ability to explain analytical choices, visual design and technical concepts to different audiences.

Unlocked: teaching + explanation + data storytelling.
Current // Data Analyst

Build the analytical system

Current work in higher education goes beyond individual reports: reconstructing definitions from source records, building reusable analytical fact tables, developing Power BI measures, improving data quality and contributing to wider data-infrastructure and governance discussions.

Current build: data architecture + BI + governance + institutional analytics.
Passive Skills

Explain
