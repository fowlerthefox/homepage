# Ciaran Sheelan - GitHub Pages portfolio

This folder is ready to upload to the root of the `homepage` GitHub repository.

## Main pages
- `index.html` - homepage / game menu
- `projects.html` - project selector
- `gaa-analytics.html` - Gaelic football research and tagging app
- `soccer-analytics.html` - Bellurgan FC case study
- `data-bi.html` - professional data analytics and BI work
- `research.html` - academic research, publication and teaching
- `experience.html` - career journey (narrative, not CV layout)
- `404.html` - custom GitHub Pages 404

## Assets
- `assets/styles.css` - shared styling
- `assets/site.js` - tiny shared script
- `assets/soccer/` - optimised images extracted from the Bellurgan analysis deck
- `assets/bellurgan_fc_analysis_coach_deck.pdf` - full soccer analysis deck linked from the case study

## Upload to GitHub
Upload the contents of this folder to the repository root, keeping the `assets` folder structure intact. Commit the changes to `main`. GitHub Pages should then update automatically.

## Timeline note
The site deliberately uses broad year labels rather than exact month-by-month dates for the career journey. This keeps the presentation portfolio-style and avoids encoding uncertain month dates. You can edit the labels later in `experience.html` if required.

## Privacy
Phone numbers and referee contact details from the CV are intentionally not included on the public site. The footer links to GitHub and LinkedIn only.
