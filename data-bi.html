Current focus

Higher education analytics

Current work includes translating detailed administrative and regulatory source records into reusable analytical structures. This involves reconciling code sets, documenting population definitions, building fact/dimension models and ensuring that Power BI measures use consistent logic.

The goal is to reduce the distance between what a KPI says and how the underlying student-level data actually produces it.

Principle

Dashboards are an interface, not the data strategy

Working principle: a Power BI report is only as reliable as the population definition, data model, transformation logic and quality checks behind it. My current work increasingly focuses on those foundations, including governance and data-infrastructure questions rather than dashboard production in isolation.
